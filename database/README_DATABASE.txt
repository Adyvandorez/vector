VECTOR INVOICE - DATABASE UTAMA
================================

Gunakan hanya file:
  vector_invoice_production.sql

File tersebut berisi struktur dan seluruh data lama yang dipertahankan, ditambah
penyempurnaan akun pelanggan, role admin, histori status, notifikasi, dan tabel
pendukung integrasi API.

Folder legacy/ berisi SQL versi lama dan patch historis. Jangan mengimpor file di
folder legacy secara bersamaan dengan database utama.

Database yang digunakan aplikasi:
  vector_invoice
